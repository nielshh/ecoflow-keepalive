Keep EcoFlow Cloud MQTT Telemetry Flowing

A lightweight headless Chromium container that keeps an authenticated EcoFlow User Portal session open so your Home Assistant EcoFlow integration continuously receives live battery and power stats.

View GHCR Package Source on GitHub

Built for Hands-Off Reliability

Scheduled Clean Restarts

Automatically exits after a configurable interval (default 4 hours) so Docker brings up a fresh Chromium session before stale tokens build up.

Crash & Memory Protection

Configured with shm_size: 512mb, Docker-safe Chromium flags, and a page crash listener that triggers an automatic restart instead of hanging.

Low CPU Footprint

Disables CSS animations and transitions on load to keep idle resource usage minimal on Raspberry Pi, Mac mini, or NAS hosts.

Quick Start

Pull the prebuilt multi-arch image from GitHub Container Registry with Docker Compose or docker run.

Configuration

Supported environment variables
Variable Required Default Description
ECOFLOW_EMAIL Yes — Email address for your EcoFlow account.
ECOFLOW_PASSWORD Yes — Password for your EcoFlow account.
ECOFLOW_REGION No eu Portal region path segment (e.g. eu or us).
ECOFLOW_COUNTRY No empty Optional country name to pick from the portal country selector (e.g. Netherlands).
RESTART_INTERVAL_HOURS No 4 Hours to keep the dashboard open before exiting for a fresh Docker restart.
DEBUG_SCREENSHOTS No false Set to true to write diagnostic screenshots into SCREENSHOT_DIR.
SCREENSHOT_DIR No /app/output Directory inside the container used when DEBUG_SCREENSHOTS=true.
ECOFLOW_USER_AGENT No Chromium default Optional custom User-Agent override.

Troubleshooting

  • Page crashed error: Ensure shm_size: "512mb" (or --shm-size=512mb) is set. Docker's default 64 MB /dev/shm causes Chromium tabs to crash.
  • Login stays on /login: Verify ECOFLOW_EMAIL, ECOFLOW_PASSWORD, and ECOFLOW_REGION (or set ECOFLOW_COUNTRY if your portal defaults to another country).
  • Inspecting login issues: Temporarily enable DEBUG_SCREENSHOTS=true with a ./output:/app/output volume mount, inspect the saved PNGs, and remove them afterward.
